# FunClip 使用说明（AI 视频切片工厂）

> 阿里 ModelScope 官方开源（FunASR 团队），GitHub 6.3k+ Star，持续更新中。
> 把**长视频/音频**（直播回放、访谈、播客、课程、剧集）一键变成**带字幕的爆款切片**：
> 本地语音识别 → 大模型挑高光片段 → 自动裁剪 → 烧录字幕，全程本地、零 API Key。
> 与「AI 短视频工厂」（MoneyPrinterTurbo）互补：那个是从零生成，这个是切你已有的素材。

---

## 一、怎么启动 / 关闭

| 操作 | 方式 |
|------|------|
| 启动 | 双击 **`启动FunClip.bat`**，黑框出现后浏览器**自动打开** http://127.0.0.1:8315 |
| 关闭 | 直接**关掉黑框窗口**；或双击 **`关闭FunClip.bat`** |

> - 首次启动要下载识别模型（约 1.5GB，已缓存到本项目 `model_cache/`，之后秒级）
> - 每次启动，模型加载进内存约需 **1~2 分钟**，黑框看到 `Running on local URL` 即就绪；页面若显示"加载中"请**再等 1 分钟刷新**，首次渲染较慢属正常
> - 已自动处理：系统代理 Clash 不会拦本机地址（NO_PROXY 已写入启动脚本）

## 二、用 WebUI 切一片（三步）

1. **上传视频**（或音频）到「视频输入」，点 **「🎯 识别 | ASR」**
   - 想区分说话人就点「识别+区分说话人 | ASR+SD」，之后可按"说话人1/2"裁剪（访谈/播客神器）
2. 识别完成 → 左侧出现全文和 SRT 字幕 → 点 **「🧠 LLM智能裁剪+字幕 | AI Clip+Subtitles」**
   - 大模型（本地 qwen2.5:3b）会自动挑出 ≤4 条精彩片段
   - 界面左上 LLM 模型框已预选 `litellm/ollama/qwen2.5:3b`（本地、免费）；也可换成 deepseek-chat 等（需填 APIKey）
   - 也可以不用 AI：从识别结果里复制你想要的句子到「待裁剪文本」框，直接裁剪
3. 右侧直接**预览成片并下载**，字幕已烧录（字体/大小/颜色可调）

**Prompt System 框可改裁剪逻辑**，比如改成"挑出最有梗的3条""每条不超过20秒""优先包含结论句"，改完再点 AI 裁剪即可，非常灵活。

## 三、批量切片（命令行，可挂定时任务）

把要切的长视频丢进 `test_videos/` 文件夹（或改脚本里的路径），然后：

```
.venv\Scripts\python.exe 批量切片.py
```

- 自动逐个识别 → 大模型选片 → 裁剪+字幕，结果存到 `output/<视频名>/`
- 识别模型只加载一次，多视频连跑很快
- 本机实测：31 秒语音识别 4 秒、大模型选片 1 秒、2 个视频批量全链路约 2 分钟

## 四、这个项目用了你电脑的什么

| 组件 | 说明 |
|------|------|
| FunASR Paraformer | 阿里语音识别模型，约 1.5GB，缓存在 `model_cache/`，CPU 跑就很快（RTF 0.03） |
| Ollama qwen2.5:3b | 选高光片段的本地大模型（和 AI 短视频工厂共用） |
| litellm | 大模型统一接口，启动脚本已指向本机 Ollama |
| ffmpeg | 系统已装（9.0） |

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 页面一直"加载中" | 等 1 分钟刷新；确认黑框里已出现 `Running on local URL` |
| 大模型选片报错/没解析出时间戳 | Ollama 没启动（启动脚本会自动拉起）；或模型输出格式怪，重试一次（本项目已增强时间戳解析，兼容多种写法） |
| 识别文字有小错 | Paraformer 偶发同音字错误，裁剪前可直接在文本框里改正再裁剪 |
| 速度想更快 | 可把 torch 换成 CUDA 版（你的 4080 会自动用上），见 `docs/installation.md` |
| 想要更好的识别 | 界面启动参数支持 `--model fun-asr-nano` 或 `sensevoice`（改启动 bat 最后一行） |
