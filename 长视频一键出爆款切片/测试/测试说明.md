# FunClip 测试套件说明

本项目（长视频一键出爆款切片 / FunClip）的**全部测试**都集中在本目录。
运行方式（项目根目录）：

```bat
:: 全量测试（含端到端/REST/WebUI/LLM 慢测试，约 8~12 分钟）
.venv\Scripts\python.exe 测试\run_all_tests.py

:: 快速回归（跳过 4 个慢测试，约 1 分钟）
.venv\Scripts\python.exe 测试\run_all_tests.py --quick

:: 只跑名字带关键词的测试
.venv\Scripts\python.exe 测试\run_all_tests.py --only REST

:: 全部通过后自动运行 关闭FunClip.bat 收尾
.venv\Scripts\python.exe 测试\run_all_tests.py --close

:: 无人值守补跑循环：检查 11 份报告，缺哪个补哪个，直到全绿（本机夜间
:: 跑着其他 AI 任务、进程偶发被系统掐死时用它磨）
.venv\Scripts\python.exe 测试\补跑循环.py 6
```

## 目录约定

- **产物一律落在本目录 `产物/` 下**：`日志/`（每个测试的完整输出、WebUI 启动日志）、
  `报告/`（单个测试的 JSON 明细）、`转写/`（识别全文/SRT/LLM 输出）、
  `切片/`（端到端成片）、`api/`（REST 下载的成片）、`抽帧/`（字幕烧录对比帧）、
  `状态/`（state 读写往返临时文件）。
- `测试报告.md` / `测试报告.json`：`run_all_tests.py` 的汇总报告。
- `制作测试素材.py`：重新生成 `test_videos/` 下的两个测试长视频
  （需装 edge_tts 的 Python，如 MoneyPrinterTurbo 的 venv）。
- `上游遗留/`：原 `funclip/test/` 的上游自带文件，仅存档。

## 历史问题回归点（测试专门盯防）

1. `pre_proc("")` 空文本 IndexError → test_02 / test_06 / test_09（空文本裁剪）
2. 无音轨视频 `sys.exit` 杀死整个服务 → test_09（无音轨上传后服务仍存活）
3. REST 切片任务忽略返回值、glob 旧文件充数 → test_09（空文本必须明确 error）
4. 本机 Ollama 无 qwen2.5:3b → test_11（默认模型必须在位）
5. 上传文件名乱码落盘 → test_09（新落盘文件名必须 ASCII 安全）
6. LLM 时间戳输出格式漂移 → test_02（九种格式兼容）+ test_11（真实推理）
7. 关闭脚本漏关接口服务 8335 → test_10（两端口都要关干净）
