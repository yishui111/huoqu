# MoneyPrinterTurbo · 接口文档

> **项目用途**：AI 短视频从零生成——给一个主题/文案，自动「写文案（LLM）→ 匹配素材 → 生成字幕 → TTS 配音 → 合成成片」。
> 两个入口：Streamlit 网页（`webui.bat`，8501，给人用）和上游自带的 FastAPI（`main.py`，8080，给程序用，自带 /docs 交互页）。

- 启动：`.venv\Scripts\python.exe main.py`（或直接 `webui.bat` 起 WebUI）
- 地址：`http://127.0.0.1:8080`（config.toml `[app] listen_port` 可改）；交互文档 `http://127.0.0.1:8080/docs`
- ✅ 本机已实测启动，以下端点列表直接取自 `/openapi.json`（2026-09-29，v1.3.7）

## ⚠ 使用前提（本机当前未配置）

`config.toml` 里所有 `api_key` 为空：出片依赖
1. 素材来源 pexels（需 `pexels_api_keys`）；
2. 文案生成 LLM（`llm_provider`，当前指向本地 Ollama，需 `ollama pull` 模型）；
3. 配音 edge-tts 免费可用（默认无需 Key）。
补齐 Key 后以下接口即可跑通。

## 接口一览（v1）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/ping` | 健康检查 |
| **任务主链路** | | |
| POST | `/api/v1/videos` | 创建视频生成任务（AIGC 成片主入口） |
| GET | `/api/v1/tasks` | 任务列表 |
| GET | `/api/v1/tasks/{task_id}` | 查单个任务进度/结果 |
| DELETE | `/api/v1/tasks/{task_id}` | 删除任务 |
| GET | `/api/v1/download/{file_path}` | 下载产物（成片/字幕等） |
| GET | `/api/v1/stream/{file_path}` | 流式播放产物 |
| **辅助生成** | | |
| POST | `/api/v1/scripts` | LLM 生成视频文案（视频脚本） |
| POST | `/api/v1/terms` | LLM 生成关键词（用于素材搜索） |
| POST | `/api/v1/audio` | TTS 生成配音音频 |
| GET/POST | `/api/v1/musics` | 背景音乐：GET 列表 / POST 上传 |
| GET/POST | `/api/v1/video_materials` | 视频素材：下载/匹配候选 |
| POST | `/api/v1/subtitle` | 生成/嵌入字幕 |
| POST | `/api/v1/social-metadata` | 生成标题/标签等社媒元数据 |

## 典型调用链（生成一条视频）

```bash
# 1) 健康检查
curl http://127.0.0.1:8080/ping

# 2) 创建视频任务（参数很多，完整 schema 见 /docs；下面是最小示例）
curl -X POST http://127.0.0.1:8080/api/v1/videos \
  -H "Content-Type: application/json" \
  -d '{"video_subject":"勤俭节约的美德","voice_name":"zh-CN-XiaoxiaoNeural","n_streams":1}'

# 3) 轮询任务直到 progress=100
curl http://127.0.0.1:8080/api/v1/tasks/{task_id}

# 4) 下载成片
curl -o 成片.mp4 http://127.0.0.1:8080/api/v1/download/<task_id>/final-1.mp4
```

> 完整请求体字段（视频比例、剪辑、字幕、配音音色、素材来源等几十项）以
> `http://127.0.0.1:8080/docs` 的交互文档为准——那是上游随代码自动生成的权威定义。
