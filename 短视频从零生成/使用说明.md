# MoneyPrinterTurbo 使用说明（AI 短视频工厂）

> GitHub 3万+ Star 的开源项目：输入一个主题，AI 自动「写文案 → 配配音 → 配画面 → 加字幕 → 合成竖屏成片」，支持**一次批量生成多条**。
> 本机已全部配置完成，**双击即用**，大模型走你自己的本地 Ollama，不需要任何 API Key。

---

## 一、怎么启动 / 关闭

| 操作 | 方式 |
|------|------|
| 启动 | 双击 **`启动AI短视频工厂.bat`**，黑框出现后浏览器会**自动打开** http://127.0.0.1:8501 |
| 关闭 | 直接**关掉黑框窗口**；或双击 **`关闭AI短视频工厂.bat`** |

> 启动时黑框是服务程序，最小化即可，别删项目文件夹。

## 二、做一条视频的完整流程（WebUI）

1. **视频主题**：填一句话，如 `为什么猫咪总在半夜突然跑酷` → 点 **「✨ 点击使用AI生成视频文案和关键词」**（本地大模型写文案，约 10~30 秒）。
   - 也可以不点 AI，直接在「视频文案」框里粘贴你自己写好的文案（跳过大模型，更快）。
2. 右侧栏推荐设置（已按短视频调好）：
   - 视频比例：**竖屏 9:16（抖音视频）**
   - 单个片段最大时长：3 秒
   - **同时生成视频数量：想批量出片就调大**（如 5，一次出 5 条不同剪辑的成片）
3. 点底部 **「生成视频」**，等进度条走完。
4. 成片位置：`storage/tasks/<任务ID>/final-*.mp4`（界面里也能直接预览/下载）。

## 三、画面素材从哪来（重要）

- **本地素材（默认可用，零配置）**：把你的视频片段放进 `storage/local_videos/`，在界面「视频来源」选不上传时，用 CLI 或界面 **上传素材** 即可。项目里已放了 3 个示例素材（素材A/B/C.mp4）方便你先试手。
- **在线素材（效果更好，需免费 Key）**：注册 https://www.pexels.com/api/ （免费）拿到 API Key，打开 `config.toml` 填到 `pexels_api_keys = ["你的key"]`，界面选 Pexels 即可自动按关键词下载高清竖屏素材。

## 四、大模型配置（已配好，可升级）

当前 `config.toml` 已配置：

```toml
llm_provider = "ollama"
ollama_model_name = "qwen2.5:3b"   # 本地、免费、约 2GB 显存
```

- 前提：Ollama 正在运行（开机自启的服务，一般不用管）。
- 想要更快更好的文案：注册 DeepSeek（https://platform.deepseek.com ）拿 Key，把 `llm_provider` 改成 `"deepseek"` 并填 `deepseek_api_key`，文案生成只要几秒。
- 机器上另拉了 `qwen3.5:4b`（3.4GB），但实测它写文案**不带标点**会导致字幕整段粘连，所以默认用 `qwen2.5:3b`；`qwen3.5:4b` 留给「解说模型」工作台用。

## 五、配音与字幕（开箱即用）

- 配音默认 **edge-tts 微软语音**（`zh-CN-XiaoxiaoNeural` 萝莉音等几十种音色，界面可选），免费、需要联网。
- 字幕默认跟随配音自动生成并**烧录**进视频，字体/大小/颜色/位置都能在界面调。
- 背景音乐：`resource/songs/` 已内置几首，`BGM` 选 random 自动配；想用自己的歌丢进去即可。

## 六、批量出片的其他姿势

- 界面：调大「同时生成视频数量」。
- 命令行（可写脚本定时跑）：编辑 `测试批量出片.py` 里的主题/数量，双击运行即可，日志在 `测试运行日志.txt`。

## 七、常见问题

| 问题 | 处理 |
|------|------|
| 浏览器没自动开 | 手动访问 http://127.0.0.1:8501 （黑框里有地址） |
| 生成很慢 | 文案生成取决于大模型（本地 3b 约 10~30 秒）；视频合成约 1~2 分钟/条，属正常 |
| 配音失败/超时 | edge-tts 需要联网；重试一次，或在界面换一个音色 |
| 想要 GPU 加速 | `config.toml` 已设 `video_codec = "h264_nvenc"`（你的 RTX 4080 会在支持时自动启用） |
| 端口 8501 被占 | 启动 bat 里把 `--server.port=8501` 改成别的端口即可 |
