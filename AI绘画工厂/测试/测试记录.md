## 4. 部署中发现并解决的问题（重要经验）

| 问题 | 根因 | 解决 |
|------|------|------|
| torch 装完 import 崩溃（cudnn DLL 126） | 首次 pip 被中断后残留半截安装，新旧文件混装 | 清空 `site-packages/torch` 与 `~orch` 残留后重装 |
| 模型加载报 `cumprod() received numpy.ndarray` | Fooocus 配套 numpy 1.26 下 `make_beta_schedule` 个别分支返回 numpy | 给 `ldm_patched/modules/model_sampling.py` 加 `torch.as_tensor()` 转换（1 行补丁） |
| gradio 启动后自杀 "localhost is not accessible" | 系统代理（Clash）拦截本机自检请求 | 启动 bat 注入 `NO_PROXY=127.0.0.1,localhost` |
| 页面全部请求 500 `unhashable type: 'dict'` | pip 装了太新的 fastapi 1.41/starlette 1.7，与 gradio 3.41 不兼容 | 降级 fastapi==0.103.2 + starlette==0.27.0 + pydantic==2.5.3 |
| 默认端口 7860 被占 | 本机 pyVideoTrans 占用（保留未动） | 改用 `--port 8188` |
| 首次批量 OOM 崩溃 | 空闲 UI 实例占了 8GB 内存，系统仅剩 5GB | 关掉 UI 实例再跑批量；**批量脚本和网页界面不要同时开** |
| 中文提示词关键元素丢失 | SDXL 不理解中文 | 批量脚本内置本地大模型中译英（自动检测，失败回退原文） |

## 5. 已知限制（如实记录）

1. **小模型翻译偶发不稳**：qwen2.5:3b 个别句子翻译后仍夹中文（脚本已自动重试一次并兜底），想要更稳可在 `批量出图.py` 顶部把 `OLLAMA_MODEL` 换成你 Ollama 里更大的模型。
2. **后台运行偶发被杀**：电脑同时开很多程序时批量进程可能被内存压力终止。**建议双击 `批量出图.bat` 在前台独占运行**，大批量放在空闲时段。
3. Fooocus 为 2.5.5 版（官方已归档维护，功能完整稳定）。
