# AI绘画工厂 · 使用说明

> 一句话批量出高清图：AI 壁纸 / 头像 / 推文配图 / 视频封面 / 插画。
> 基于 GitHub 4 万+ Star 的 Fooocus（Stability 出品团队同源），专为不会调参的小白设计。
> 模型与翻译全部本地运行（RTX 4080 秒级出图），**零 API Key**。

---

## 一、启动 / 关闭

| 操作 | 方式 |
|------|------|
| 启动 | 双击 **`启动AI绘画工厂.bat`**，浏览器自动打开 http://127.0.0.1:8188 |
| 关闭 | 关黑框，或双击 **`关闭AI绘画工厂.bat`** |

> - 首次启动会自动下载绘画模型（约 7GB，走国内镜像），之后秒开
> - 每次启动加载模型约 1~2 分钟，黑框出现 `Use via API` 字样或浏览器自动打开即就绪

## 二、网页出图（最简单）

1. 在提示词框输入一句话（**中英文都行**），点 **Generate**
2. 想批量：勾选 **Advanced** → 「Image Number」调到 8/16（一次出多张）
3. 图片自动保存在 `Fooocus/outputs/日期/`，画布下方直接查看/下载

**常用玩法**：
- 头像号：`中国风少女头像，精致五官，柔和光线 | 8 | 896*1152`
- 壁纸号：`赛博朋克城市夜景，霓虹雨后，电影感 | 8 | 1152*896`
- 推文配图：`恐怖老宅夜景，闪电，诡异氛围 | 4 | 1152*896`

## 三、批量出图（挂机神器，推荐）

1. 编辑 **`批量提示词.txt`**，一行一条，格式：
   ```
   提示词 | 张数 | 比例
   ```
   （张数、比例可省略；`#` 开头的行是注释）
2. 双击 **`批量出图.bat`**（命令行版：`.venv\Scripts\python.exe 批量出图.py`）
3. 自动：中文提示词 → 本地大模型翻译成英文 → 出图 → 汇总复制到 `测试/产物/`

> ⚠️ 注意：
> - 批量脚本运行时**不要同时开网页界面**（内存会不够）
> - 提示词写中文即可，脚本会自动调用本地 qwen2.5:3b 翻译成英文（无 Ollama 时用原文）
> - 电脑同时开很多程序时建议空闲时段挂机批量

## 四、配合短视频生产（与你的其他项目联动）

```
AI绘画工厂(出插画) ──→ AI短视频工厂 MoneyPrinterTurbo（选"本地素材"模式上传这些图做视频）
                └──→ 剪映手动精修
```

## 五、常见问题

| 问题 | 处理 |
|------|------|
| 页面打不开 | 看黑框是否已出现地址；等模型加载完（1~2 分钟）再刷新 |
| 出图很慢/失败 | 关掉其他吃显存的程序（GPT-SoVITS、3D 服务等）；批量时关掉网页界面 |
| 翻译偶发夹中文 | 小模型正常现象，重跑一次即可；或把 `批量出图.py` 里 `OLLAMA_MODEL` 换更大模型 |
| 想要不同画风 | 勾选 Advanced → Styles 选风格（Fooocus V2、电影胶片、动漫等 40+ 种） |
| 显存不够 | 高级设置里把 Performance 从 Speed 改为 Quality 会更慢但更省；或分辨率调低 |

## 六、文件夹结构

```
AI绘画工厂/
├─ 启动AI绘画工厂.bat      ← 双击启动
├─ 关闭AI绘画工厂.bat      ← 双击关闭
├─ 批量提示词.txt          ← 批量任务清单（编辑这个）
├─ 批量出图.py             ← 批量引擎（含中译英）
├─ 批量出图.bat            ← 双击跑批量
├─ 测试/                   ← 测试记录 + 截图 + 产物
└─ Fooocus/                ← 上游源码 + 模型 + 产物(outputs/)
```
