# AI绘画工厂 · 接口文档

> **项目用途**：一句话批量出图（Fooocus/SDXL 封装）——提示词 → 抠背景 → 风格预设 → 出壁纸/插画/封面。
> 两个入口：Gradio 网页（`启动AI绘画工厂.bat`，8188）和本 REST 服务（`启动接口服务.bat`，8189，给程序用）。

- 启动：双击 `启动接口服务.bat`（或 `python api_server.py`，用系统 Python 即可，无第三方依赖）
- 地址：`http://127.0.0.1:8189`
- 架构：每个生成任务在**子进程**里跑 `批量出图.py`（Fooocus venv）——单任务崩溃不影响服务本身

## ⚠ 当前已知限制

本机 Fooocus venv 的 torch 2.1.0 在模型加载阶段段错误（exit 139，详见 `..\测试\测试报告.md`）。
在此问题修复（升级 torch）之前：**接口全部可用，但生成任务会如实返回 error**；
修复后无需改接口，任务即恢复出图。

另：Clash 代理未开时，Fooocus 启动期的联网检查（GitHub 版本校验）会长时间挂起
（CPU/GPU 均为 0、任务停在 running）——开代理或耐心等其超时即可；此为 Fooocus 上游行为。

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查（venv 是否存在等） |
| POST | `/api/generate` | 提交出图任务（异步） |
| GET | `/api/job/{id}` | 进度 `queued → running → done/error` |
| GET | `/api/result/{id}` | 下载结果：默认第一张 png；`?all=1` 打包 zip |

## 调用示例

```bash
# 提交（比例可选 1152*896 / 896*1152 / 1216*832 / 832*1216 / 1024*1024）
curl -X POST http://127.0.0.1:8189/api/generate \
  -H "Content-Type: application/json" \
  -d '{"prompt":"一只戴宇航员头盔的橘猫，电影感光影","count":1,"ratio":"1152*896"}'
# → {"ok":true,"data":{"job_id":"c8358eec0e7a"}}

# 轮询（首次含模型加载需数分钟；done 时 images 为文件名列表）
curl http://127.0.0.1:8189/api/job/c8358eec0e7a

# 下载
curl -o 出图.png http://127.0.0.1:8189/api/result/c8358eec0e7a
curl -o 全部.zip "http://127.0.0.1:8189/api/result/c8358eec0e7a?all=1"
```

## 参数说明（POST /api/generate）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| prompt | str | 必填 | 出图提示词（中文可，Fooocus 自带风格扩写） |
| count | int | 1 | 张数 |
| ratio | str | 1152*896 | 比例，见上表 |
